# CS-305-Portfolio
CS 305 Software Security Portfolio

## CS 305 Module Eight Journal Reflection

### 1. Client and Software Requirements

Artemis Financial is a financial consulting company that helps clients manage their financial information. The company needed to improve the security of its software application to protect sensitive information from unauthorized access. My responsibility was to identify security vulnerabilities and recommend improvements that would make the application safer and more reliable.

### 2. Identifying Security Vulnerabilities

One thing I did well was identify potential security risks by reviewing the application's code and dependencies. Secure coding is important because it helps protect customer information and prevents security breaches. Strong software security also helps companies maintain customer trust and avoid financial losses.

### 3. Challenges During the Assessment

One of the most challenging parts of the vulnerability assessment was understanding the dependency-check results and determining which vulnerabilities needed attention. However, this process helped me understand how security tools identify potential weaknesses and why reviewing the results carefully is important.

### 4. Increasing Layers of Security

I improved the application's security by implementing encryption-related security measures and reviewing dependencies for vulnerabilities. In future projects, I would continue using dependency-check tools, code reviews, and security testing to identify risks and determine appropriate solutions.

### 5. Testing the Application

After making changes to the application, I used testing and Maven build results to help verify that the software was functioning correctly. I also reviewed dependency-check results to identify possible vulnerabilities. These steps helped me understand the importance of testing software after making security improvements.

### 6. Helpful Resources and Tools

Throughout this project, I used Eclipse, Java, Maven, and dependency-check tools. These resources helped me understand how to identify vulnerabilities, improve software security, and troubleshoot coding problems. I plan to use these skills and tools in future programming assignments and professional projects.

### 7. Skills to Show Future Employers

I would show future employers my Artemis Financial security report as an example of my ability to evaluate software vulnerabilities and apply secure coding practices. This project demonstrates my experience with security testing, problem-solving, and documenting improvements to a software application. It also shows my understanding of why software security is important in protecting businesses and their customers.
